## Lyrics Analysis

### Summary
仕事帰りの「いつもの道」と、かつて同じ道を「君」と走った記憶が重なっていく。名前も知らないラジオ曲は、最初は帰宅時刻を知らせる生活の目印として現れるが、流れなくなった瞬間に、語り手が本当に待っていたのは曲そのものではなく「その曲を聴いていた頃の自分」だったと気づく。大きく何かを取り戻すのではなく、夜明け前にラジオを切り、家へ帰ることで閉じる。

### Themes
- 深夜の帰路と過去の自己の重なり
- 記憶が出来事ではなく感覚の断片を残すこと
- 音楽が時間・場所・自己を結びつけること
- 帰る場所があっても、帰りきりたくない感情
- 過去へ戻るのではなく、過去の自己の残響を認識すること

### Core Keywords
- 午前零時
- ラジオ
- いつもの道 / いつもの橋
- 百円玉
- 君
- あの曲
- あの頃の僕
- 家
- 晴れ

### Symbols / Motifs
- **ラジオ:** ひとりの帰路に寄り添う外部の声。後半では過去の自己への入口になる。
- **いつもの道 / 橋:** 現在と過去を重ねる固定舞台。場所は変わらず、そこに載る意味だけが変わる。
- **百円玉:** 反復される生活ディテール。Outroで再登場し、現在へ戻る目印になる。
- **助手席:** 現在では他人の車、過去では「君がいた」場所として対応する。
- **缶コーヒー / 白い息 / 冷たい風:** 記憶を身体感覚へ結びつける小道具。
- **夜明け / 青くなる空 / 晴れ:** 解決ではなく、帰宅へ戻る時間の進行。

### Perspective
一人称「僕」が、現在の深夜帰宅を淡々と描写しながら、同じ道に残る過去の記憶へ滑り込んでいく。過去の「君」への直接的な語りかけではなく、自分自身の記憶の残り方を観察する視点が中心。

### Narrative / Semantic Progression
1. 午前零時、仕事を終えて車に乗り、ラジオが鳴る。
2. 名も知らない曲が帰宅の目印になっている。
3. 「もう少し走っていたかった」という理由未確定の感情が出る。
4. 同じ道に「君を送った夜」が重なる。
5. 次の夜、同じ曲を待つが流れない。
6. 曲が流れないことで、自分がそれを待っていたことを自覚する。
7. Final Chorusで「待っていたのはあの歌じゃない / あの頃の僕」と対象が反転する。
8. Outroでは百円玉・橋へ戻り、ラジオを切り、家へ向かう。

### Repetition / Contrast / Notable Wording
- 「いつもの道 / いつもの橋 / 同じ信号 / 同じ橋」と場所の不変性を反復する。
- 現在の「助手席で誰かが眠ってる」と、過去の「助手席に君がいたこと」が対応する。
- 「題名も知らない / 誰が歌ってるかも知らない」のに、その曲だけで帰宅時刻と場所が分かる。
- 「あの曲を待っていた」から「待っていたのはあの歌じゃない」へ対象が反転する。
- 結末は感傷への没入ではなく、「晴れ」「家まであと十分」という現在へ戻る。

## Structure Analysis

- **Structure type:** hybrid: linear_narrative + dual_layer + contrast_reversal
- **Summary:** 現在の深夜帰宅を一本道で進めながら、同じ道の過去が二重写しになる。Bridgeで曲の不在がトリガーとなり、Final Chorusで「待っていた対象」が曲から過去の自分へ反転する。

~~~mermaid

    P1[過去の層<br/>君を送った同じ道]

    F[Final Chorus<br/>待っていたのは歌ではなく<br/>「あの頃の僕」]
    O[Outro<br/>百円玉 / 橋 / 晴れ<br/>ラジオを切って家へ]
    N1 --> C1 --> P1 --> C2 --> B --> R --> F --> O
    N1 -. 同じ道 .-> P1
    R -. 対象の反転 .-> F
~~~

### Structural Notes
- Verse 1とVerse 2は「同じ道」の現在と過去を分担している。
- Chorus 1の「もう少し走っていたかった」は理由を残し、Final Chorusで遅れて意味が与えられる。
- Bridgeは「曲が流れない」という欠落によって、それまで無意識だった待機を意識化する。
- OutroはIntroと同じ帰路の具体物へ戻るが、空だけが「青くなる」。
